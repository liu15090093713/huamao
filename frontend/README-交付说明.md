# 今晚花毛 Web 前端

一个围绕“同城当晚现煮花生毛豆”重新设计的响应式品牌与点单首页。

## 已包含

- 桌面端与移动端响应式页面
- 今日开锅、限量与预计送达信息
- 品牌故事、鲜煮承诺、消费场景内容
- 商品分类筛选
- 商品加入、加减数量、购物车金额计算
- 满 49 元免配送费提示
- 浏览器本地购物车保存
- 预订单演示反馈
- 无障碍标签与减少动态效果适配

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 上线前需要替换

页面中的开锅时间、配送半径、每日限量、商品价格和制作故事均为品牌方案示例；上线前请替换为真实经营信息。

当前“提交预订单”是前端演示，不会发起支付。接入现有 Java 后端时，可在 `app/page.tsx` 的 `submitDemoOrder()` 中调用订单提交接口，并将 `products` 替换为菜品接口返回的数据。

## 安全提醒

不要把微信支付密钥、AppSecret、数据库密码或管理员默认密码写入前端或提交到代码仓库。正式环境应使用服务端环境变量，并在上线前轮换已有测试密钥。
